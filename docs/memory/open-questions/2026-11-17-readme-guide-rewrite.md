# README and operational guide rewrite

## Finding/decision

The README and the agents' guide grew release by release; the person needs a guide to run the system, apart from the agents' reference.

Recommendation (drafted by coder2 from master's directive of 2026-11-17; master to confirm or edit): The docs agent writes it once the v0.29 features settle: a short README, an operator's guide for the person, the agents' guide kept as the protocol reference.

## When it applies

Before a release meant for other users, or when the person cannot find how to do something.

## Evidence

[README.md](../../../README.md), [docs/AGENT-BUS-GUIDE.md](../../AGENT-BUS-GUIDE.md).

## Limits / what would invalidate it

A rewrite while features still move would be stale at once.
