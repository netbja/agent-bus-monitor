## Roadmap at this checkpoint (proposed, numbering agreed with Bernard)

1. **v0.21.1: herdr's native restore through the launcher.**
   - `agent-launch` reports its own resume command,
     `pane report-agent … -- agent-launch <role> <p> [--resume <id>]`, so that after a herdr
     restart an agent comes back with its rules and identity. See the herdr 0.9.5 docs
     `session-state.mdx` and `add-herdr-support.mdx`.
   - Open question first: herdr's Claude Code integration (`herdr:claude`) already holds those
     panes and restores a raw `claude --resume`. That bypasses the launcher, and is a likely cause
     of a resumed master losing its identity. The docs say other reporters should use metadata
     rather than take a pane over.
   - Test in a separate herdr session with Bernard attached: restore runs only once a client
     attaches.
2. **v0.22: busmon UX.**
   - Icons per provider when the font is present (`fc-list`), else text, behind a busmon.toml
     `glyphs` setting. Codepoints: claude E1A0, codex E1A1, kimi E1A6, grok E1B1, agy E1B2,
     gemini E1AE. Lifecycle marks: done E1C0, blocked E1C1, idle E1C2, unknown E1C3.
     `setup.sh status` reports the font; setup installs nothing third-party.
   - An Activity mark and a "for me" filter for messages that await the person.
   - `r` replies from the message overlay.
   - Mouse drag-select copy.
   - Gauge colours that follow the pace of the quota window.
   - From `docs/recon/2026-10-20-codex.md` part B: unresolved requests of vanished agents; quota
     source and freshness; empty states that name the next step; errors with a recovery action.
3. **v0.19.1 and v0.19.2.**
   - v0.19.1: a Redis password generated at install, and `./setup.sh rotate-redis-password`.
   - v0.19.2: the secret scanner, the canary, the key inventory and project-defined checks.
4. **v0.23: sentinel proactive.**
   - Task-level stalls.
   - Delivered-but-never-accepted requests, and questions older than 12 h.
   - Simultaneous failures correlated into one wake.
   - done-without-ref and two-owner checks.
   - Disk and failure trends, with time to saturation.
   - A resume-prep list for master after a recovery, and recovery verified by its effect.
   - A morning absence digest in `R`.
   - A login-expiry alert: Claude Code shows "Your login expires in 1 day · run /login to renew".
     Sentinel detects it from the observed pane text, warns the person, and never opens a
     credential.
