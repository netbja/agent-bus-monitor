- **`busmon --delete` keeps the Projects page's rules** (busmon-cli-flags, item 2): a project that is not asleep is refused with the page's reason (Z, x, or `agentbus down` first), `--yes` included, and an unknown counts as live; the hosts where its units remain are named before the question and after the delete; a backup (`agentbus backup --project <p>`) is taken just before the delete, and a failed backup deletes nothing. The archive it makes is never removed by `projects.delete_backups`. An agent's process tree is still refused (`refuseDestructive`).
