# v0.15.2 — a model table that keeps itself current

Spec: `docs/superpowers/specs/2026-10-17-swaps-history-and-model-drift-design.md` §10 and §12
(approved by Codex).

## New

- **`agentbus models`** shows the models each provider offers now, read from each client's own free
  catalogue on this machine: OpenAI (Codex's cache), Anthropic (Claude Code's aliases and options),
  xAI (`grok models`), Moonshot (Kimi's config) and Google (`agy models`). No model is called and no
  credential file is opened. `--refresh` rereads them; the sentinel does it every day and
  `setup.sh install`/`update` at the end.
- **Each model has a tier:** frontier, workhorse, fast or legacy. It comes from the provider's own
  words ("Frontier…", "Latest workhorse…", "Older…") or from your rules in
  `~/.config/agentbus/models.toml`.
- **A role can name a tier instead of a model:** `tier = "frontier"` in a `roles.toml` profile. Each
  launch takes the provider's current model of that tier, so a renamed model never breaks a launch
  and a new one is picked up at the next relaunch. `model = "<id>"` still pins a version.
- **`agentbus roles doctor` says two more things:**
  - `gone`: the provider no longer lists the model an agent runs;
  - `newer`: the provider names a newer model.

  "Newer" is reported only on stated evidence, never guessed. busmon flags both as `model≠`, and
  master asks you before relaunching with `swap --back`.

## Limits

- Claude Code lists aliases, not every id: an exact Claude id is never called `gone`.
- A failed read keeps the last good list; a list older than 7 days judges nothing.
