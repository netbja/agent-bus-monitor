# v0.26.1 — restore after a dead agent, the plugin's version, the settings page's focus

A fix release, found by restoring a real archive (a live check of v0.26.0's backups).

- **`agentbus restore` no longer refuses a project whose registered agent has died.** On Linux a
  dead agent's pid read as "cannot tell whether it is live", so such a project could never be
  restored: the check knew a missing `/proc` entry only by one error, and the process reader
  returns another. A pid `/proc` no longer lists now proves the agent gone; any other read error
  still refuses (fail closed), and a live agent, an open workspace, a held lease or an active
  service still refuse even with `--force`.
- **The herdr plugin's manifest says 0.26.1.** `herdr-plugin.toml` was left at 0.24.0 under the
  v0.26.0 tag, which turned the test suite red (the manifest test holds it to the newest tag).
  The v0.26.0 tag is unchanged.
- **busmon's settings page (`C`) shows where the focus is.** The groups or the keys have it: the
  focused side is lit, the other muted (below 96 cells the selected tab dims, as an unfocused panel's
  tab does). On the groups `↑` `↓` choose one and its keys follow, `→` or Enter go to its keys, `←`
  comes back; below 96 cells `←` `→` step the tabs, `↓` or Enter go to the keys and `↑` on the first
  key comes back; Tab moves the focus. An open choice still takes `←` `→`; Enter saves it, Esc leaves
  the file as it is. The values now sit in one column after the group's labels, not at the right edge.
- **Docs:** the operational guides (EN, FR) say that a files restore writes a project's roles
  files to the absolute path its archived template names (a checkout, not your home), so check it
  with `--dry-run` on another machine.

What the live check confirmed on v0.26.0: a backup of every project, `backup list`, a dry-run
restore against the running broker (live projects refused, existing keys refused), and a restore
into a separate Redis 8 broker whose record keys match the source in type and size. An older broker
(Valkey's 7.2-compatible version) is refused for an archive made on Redis 8, as designed. The
`--secrets` path still was not exercised (`age` not installed).

## Upgrade

```sh
./setup.sh update
```

Reopen busmon for the settings page; nothing else to restart (`agentbus restore` is a command you run).
