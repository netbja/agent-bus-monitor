# v0.21.0 — startup and relaunch

After a reboot, herdr restores a project's workspace and tabs, but the agents and the project
services are gone. Opening the project now brings them back.

**The workspace hook.** The herdr plugin listens to `workspace.created` and `workspace.focused`.
For a workspace labelled with a project that has a template and that the broker confirms, it
starts the project's stopped services and relaunches its dead agents in their existing tabs. Like
the picker, it never provisions a project. It rewrites no service unit, so a binary at another
path never restarts a running dispatcher. It creates no tab, so a retired role stays retired. It
does nothing while an `agentbus up` runs, or within a minute after one ends. Its output is in
`herdr plugin log netbja.agentbus`.

**`agentbus up <p>` on an open workspace** no longer stops at focusing it. It checks every
template tab and prints one line for each: `alive`, `relaunched`, `relaunched (new tab)`,
`skipped (busy)` or `unknown`.

- **Alive or dead.** An agent is alive when its recorded pid still runs with the recorded start
  time, the identity rule the dispatcher already uses. Without a record, herdr's detected agent
  decides.
- **What gets typed.** Only a pane whose foreground is a bare shell is typed into, and only the
  template's own command. Master is relaunched first.
- **`--dry-run`** prints the plan and changes nothing.
- **`--resume`** resumes a Claude Code agent's recorded session through the launcher, so its
  rules and identity stay attached. Other clients start fresh.

**`agentbus projects`** lists every known project: its template directory, the broker's answer,
its services and its agents (alive, dead or unknown). It works without a project and with Redis
down, and ends with the `agentbus up` to run for a project with something down. `--json` gives the
same data for scripts.

**missions waits for Git.** A project directory that is not a Git repository yet no longer leaves
`missions failed` for good. The service shows `missions waiting git`, and health reports `warn`
with the remedy. It spends no restart, and starts by itself once `git init` has run.

**Your name, once.** `./setup.sh install` asks, on a terminal only, for the name you go by on the
bus. It records the name with the new `agentbus identity set <name>`, in the `[identity]` section of
`busmon.toml`; every other line of that file is kept. busmon and `agentbus up` use it as the default
`--as`, and an explicit `--as` still wins.

Install with `./setup.sh update`. The plugin is the linked checkout, so herdr reads the new
manifest from it. `herdr plugin list` should show the two events under `netbja.agentbus`.
