# v0.17.3 — shared secret-file denies for Claude Code roles

`roles.toml` now has a top-level `[tool_rules]` table. Its Claude Code permission rules are
validated and merged into every role, before role-specific rules. Repeated rules in the same list
are removed; conflicting rules across lists remain errors.

The shipped Read/Edit deny lists cover common `.env` variants (excluding `.env.example`), private
key files, SSH keys, keypair JSON and wallet JSON. Claude Code applies these denies in every
permission mode, including `bypassPermissions`.

These rules are defense in depth, not a security boundary: commands and other processes an agent
starts, including tests and dotenv loaders, can still read environment files. The agent-bus skill
recommends running betterleaks or gitleaks on changes before opening a PR when either is installed;
this is useful but never a blocker.
