# v0.14.4 — a stopped agent says why

## Fixed

- **master showed `working` while Claude's quota had stopped the project.** The dispatch service
  had done its job: Claude at 100% of its 5-hour window, the Anthropic agents held, the project
  paused until the reset, master warned. But busmon's state column still showed what each agent
  last declared.
- Now the state column shows the bus fact that stops an agent, for an agent that declared
  `working` or `idle`:
  - `quota` when its provider is at its limit (the flag `held` is no longer repeated beside it);
  - `paused` while the project is paused (the header still says until when and why).
- `blocked`, `waiting` (a person's decision) and `done` are never covered: they say something the
  pause does not.
- The agent detail keeps the declared state (`Declared  working (shown as paused)`) and adds a
  `Stopped` row with the reason. The panel title counts agents as they are shown.
