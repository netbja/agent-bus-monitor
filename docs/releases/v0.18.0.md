# v0.18.0 — busmon attention and project recap

busmon now keeps human attention visible across interruptions without writing attention state back
to the bus. It distinguishes an unanswered `waiting` declaration from one answered by a later
addressed `human=yes` message (including `@all` fan-out and a reply to the agent's thread). Equal
millisecond timestamps are not treated as ordered. An open ask remains independently outstanding
until answered, withdrawn or replaced.

Due reminders group unanswered ask questions and waiting declarations, oldest first. They open
only when busmon is not in a draft, compose window or another modal. Enter opens an ask, `i` opens a
compose window addressed to an agent who is waiting, and Esc snoozes the displayed items. Reminder
delays, snooze duration, bell and waiting fade can be configured; zero disables the reminder popup.

Press `R` for **Where was I?**. The deterministic recap shows current asks, waiting and blocked
agents, agent snapshots, board tasks, and retained changes since the previous visit. It labels read
failures and warns when a capped stream or ledger no longer covers the full interval. Pause history
is limited to the current pause record and retained resume directives; service history reports each
service's latest state. It does not infer events missing from retained history or call an LLM.

The final row can ask the project's escalation target for a summary. The target is the most recent
retained dispatcher escalation target, or `master` by default. The row is disabled while the project
is paused, when the target is not registered, or while its provider is held. Enter opens a
confirmation; only `y` sends the directive through busmon's normal `ui.send` path. The request and
reply status are inferred from retained bus commands; when that history cannot be read, the status
is shown as unavailable. The reply appears in normal Activity/thread views.

Settings are global in `~/.config/agentbus/busmon.toml`, or `$XDG_CONFIG_HOME/agentbus/busmon.toml`:

```toml
[waiting]
popup_after = "5m"
snooze = "15m"
bell = true
fade = true

[recap]
auto_after = "8h"

[display]
theme = "auto"
limit = 25

[identity]
as = ""
```

CLI flags and environment variables override file values. The local cache under
`~/.cache/agentbus/busmon/` stores only the project key, last-visit timestamp and reminder snooze
deadlines/item identities. It is written atomically with mode `0600`; it contains no message bodies,
answers or credentials. If a cache write fails, busmon continues and reports that local tracking
could not be saved.

Validation: `go build ./...`, `go vet ./...`, `AGENTBUS_TEST_REDIS_URL=redis://127.0.0.1:6392 go test ./... -count=1`, and `bash tests/run.sh`.
