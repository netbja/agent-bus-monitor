# v0.12.4 — a quieter waiting

The v0.12.3 pulse, tried on a real team, moved too much: the ♙ glyph and the header badge blinked
with the state, one hard step per second.

- **Only the word `waiting` in the state column moves.** It fades in and out over 3 seconds,
  from 20% to 100% intensity and back, eased like CSS `ease-in-out`. busmon redraws about ten
  times a second for it, and only while an agent is waiting.
- **The ♙ glyph and `♙ N waiting for you` in the header stay still.** The bell still rings once
  per new waiting declaration.
- **Without true colour** (16 colours, `NO_COLOR`) there are no shades to fade through: the word
  stays in the attention colour and nothing moves.

Upgrade: `./setup.sh update`, then reopen busmon.
