## Questions, like Claude Code's

- **`agentbus ask <agent> --file questions.json`**: a title and 1–6 questions, each with a short header
  (its tab), the question, a short Markdown context and 1–6 options (one may be recommended, with
  why). The agent is declared `waiting`. One open ask per agent.
- **In busmon, `!` or F4** opens them: one tab per question (`✓` answered, `●` current, `○` open),
  `↑↓` or a digit to pick, Enter to send **that answer at once**, `Other…` to type your own,
  `←→` / Tab between questions, Esc to close, `?` for help. The answer reaches the agent as a reply
  and wakes it; the other questions can wait.
- **An answered question never comes back.** When the agent changes its mind it replaces the ask:
  unchanged questions keep their answers, reworded ones come back as new questions. An answer given
  on the old version follows to the new one when the question did not change.
- **The header counts open questions**, not agents; an agent with open questions fades `waiting`
  whatever it declared since; the bell rings once per new ask. The agent's detail starts with its
  questions.
- **Without busmon**: `agentbus asks [--open]`, `agentbus answer <id> <question> --choice <label> | --text …`.

## Text you can read

Reports, message bodies and question context are rendered as Markdown readable in a terminal:
headings, bullet and numbered lists with a hanging indent, re-wrapped paragraphs, quotes, `code` and
code blocks. Activity rows stay one line. The skills ask agents to write reports that way.

## Upgrade

`./setup.sh update`; `agentbus --project <p> service restart dispatch`; reopen busmon. Agents pick up
`agentbus ask` from their skills at their next start (tell master once to use it now).
