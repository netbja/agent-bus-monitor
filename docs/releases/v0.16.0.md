# v0.16.0 — a compose window in busmon

Spec: `specs/2026-10-17-busmon-compose-window-design.md` (rev 2: Kimi's review of
rev 1, approved by Codex).

## New

- **A compose window for messages of several lines.** `I` opens it from any panel (on the selected
  agent in Agents) or from an agent's detail. Enter is a new line, **Ctrl+S** sends, **Esc** closes
  and keeps the draft, a click outside does the same. The header shows the recipient and what the
  message is (`directive`, or `broadcast` when there is no recipient); **Tab** moves to the
  recipient field, which completes `@agent` and `@all`. A counter shows the characters against the
  bus's limit.
- **From the line to the window.** `i` keeps the one-line input for short messages. **Ctrl+O** or **Alt+Enter** in it (the end of the line says so),
  or pasting text with several lines, moves what is typed to the window, recipient included. While
  the window holds a draft, `i` opens the window, so a long text is never squeezed into one line.
- **Pasting works.** busmon now accepts pasted text (bracketed paste); a paste longer than the limit
  is cut on a character boundary and the window says how much was dropped.
- **The same editor for a free answer.** "Other…" in the question panel opens the window for that
  question. A draft is kept per question until the answer is accepted; an answer the bus refuses
  keeps its text.
- **One send path.** The line and the window go through the same checks: the open-question hint
  (Ctrl+T in the window answers in that agent's question panel), the broadcast warning, `@all` with
  agents that failed (the window then closes and the draft is cleared, since sending again would
  reach the others twice). Text is sent as written, with Windows line endings and control
  characters removed.
- **Agents use a code index when there is one.** The `agent-bus` skill, read by every role in every
  project, now says to use a code-index MCP server (codebase-memory-mcp, codegraph) first for
  structural questions, and grep for literals.

## Upgrade

`./setup.sh update`. Agents read the updated skill on their next start.
