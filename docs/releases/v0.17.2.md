# v0.17.2 — `install.sh` removed

`install.sh` was a one-line alias of `./setup.sh install`, kept for old instructions. It is
gone. Use `./setup.sh install` (also `update`, `uninstall`, `status`). The README, CLAUDE.md,
the hint printed by the role scripts when the binary is not built, and the installer test no
longer mention it.

Update with `./setup.sh update`. Nothing else changed in the binaries.
