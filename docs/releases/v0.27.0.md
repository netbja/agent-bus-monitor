# v0.27.0 — suspend and resume the team, busmon pages for backups, notifications and About

This release gathers everything merged since v0.26.1 (PRs #291 to #306), the v0.27 batch
(`docs/plans/v0.27.json`).

**Suspend and resume the team in one gesture** (#291, #293, spec
`docs/superpowers/specs/2026-11-03-suspend-resume-design.md`):

- **`agentbus suspend`** takes every project of this host, or one with `--project`, to rest before a
  reboot or a long absence. It pauses the project, waits until the team is quiet (up to
  `suspend.wait`, 10 min), stops its services and keeps a snapshot of what was open. It is the
  person's act: refused to an agent. A timeout, a signal or repeated read errors cancel it, and the
  services start again. `suspend --status` lists the suspended projects.
- **`agentbus resume`** on a suspended project starts its services, relaunches its agents inside the
  recorded herdr session with `up --resume`, waits for each required agent to be live, then lifts
  the suspend with one summary. A resume keeps the project's env file as it is. A missing agent keeps
  the suspend unless `--partial`. `agentbus resume --all` wakes every project of the host, and also
  restarts what a crash left stopped.
- **`suspend.auto_resume`** (off by default): once the machine has rebooted, focusing the project's
  workspace resumes it in the background, once per boot.
- **The dispatcher types nothing while any pause holds**, even a wake it decided just before the
  pause.
- **busmon:** `Z` asks to suspend or resume the open project and runs it as a child, with its last
  log line as the notice. The header reads `suspended since HH:MM · by <name> · <reason>`.
  `suspend.wait` and `suspend.auto_resume` are on the settings page `C`.

**busmon's settings page `C`:**

- **Backup** (#297): the folder, `Back up now` (in the background, with its result), one row per
  archive with its coverage, and the last runs. Enter on an archive shows the restore dry runs to
  copy and what takes a project offline first: `agentbus down <p>` and its herdr workspace closed. A
  suspend is not enough, since restore refuses a live project even with `--force`. busmon restores
  nothing.
- **Notifications assistant** (#299, #305): `Set up ntfy`, `Set up Discord` and `Set up the desktop`
  open the steps, `notify.toml`'s state by name and kind only, a template `y` copies (ntfy's topic
  drawn at random and kept nowhere) and each target's last test. busmon writes nothing; you write
  `notify.toml`. #305 adds tests of the topic's bounds.

**busmon, elsewhere:**

- **About, `A`** (#300, #302, #303): the wordmark, the project, then the versions of this build
  (busmon, agentbus beside it, protocol, Go, the update check) and of this host (Redis, herdr, the
  plugin); `y` copies them. Master and coder sit on a bus line with a packet travelling between them
  (`r` replays it; it stays still with fade off, 16 colours or none). The author and the licence are at the foot.
- **For you with nothing for you** (#301) no longer repeats the In progress rows the Agents panel
  shows. It says there is nothing, then the next decision as a row Enter opens.
- **The compose window undoes** (#296): `^Z` undoes the last edit (a bad paste is one step) and `^Y`
  (or ctrl+shift+z) redoes it, up to 100 steps.
- **A wake held by a focused pane rings the desktop** (#304): when the dispatcher holds a wake
  because you are typing in that agent's pane, and its oldest message has waited
  `dispatch.focus_notice` (30 s, `0` = off, page `C`, Attention), the desktop rings once per message.
  The wake follows once the focus leaves. Nothing is typed.

**Fixes:**

- **Health `github` never opens a desktop password prompt** (#298). The probes run with no askpass
  program (`GIT_ASKPASS` and `SSH_ASKPASS` removed, `core.askPass` emptied,
  `SSH_ASKPASS_REQUIRE=never`). Before, KDE's ksshaskpass asked for a GitHub username every 15
  minutes. A private repository still counts as reached.
- **No more `Write(...)` warning at each Claude Code launch** (#294). The roles' `Write` denies of
  `config.toml` and `notify.toml`, which Claude Code never matches, are gone; their `Edit` denies
  cover the Write tool.

**Docs** (#295): the guides and READMEs (EN, FR) start a new project with `agentbus start` and say
when to use `up` instead.

## Upgrade

```sh
./setup.sh update
```

What takes effect when:

- **Restart each project's services** for the pause rule and the focus notice:
  `agentbus --project <p> service restart dispatch`.
- **Relaunch the agents** to drop the `Write(...)` warning: per idle agent,
  `agentbus --project <p> reload <role> --as <your-name>`, or exit it, then
  `agentbus up <p> --resume`.
- **Reopen busmon** for `Z`, the About page, the Backup and Notifications sections of `C`, the
  compose undo and For you.
- **Turn on auto-resume** only if you want it: `auto_resume = true` under `[suspend]` in
  `~/.config/agentbus/config.toml`, or on page `C`.
