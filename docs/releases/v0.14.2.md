# v0.14.2 — a person's answer is never lost

## Fixed

- **The second answer to an ask never reached the agent.** Bernard answered master's two
  questions five seconds apart. master woke on the first, then re-armed with a plain
  `agentbus subscribe` (no `--since`): that floors at the server's "now" and acknowledges
  everything older unseen, including the second answer. The ask showed `answered`, master
  still waited.
- A plain `subscribe` now delivers, instead of dropping, an entry below its floor when a person
  wrote it to that agent from busmon (`human=yes`), it wakes (not a `wake=no` thread close), its
  text is retained and it is younger than 24h. Everything else below the floor is skipped as
  before. An explicit `--since <id>` keeps its strict meaning: what the agent says it handled is
  not delivered again.
- `subscribe --drain` (what a woken agent runs) was never affected.

## For agents

Persisting the cursor and re-arming with `--since <id>` stays the rule (skill `agent-bus`); this
release only makes the one mistake that costs a person's decision harmless.
