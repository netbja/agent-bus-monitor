# v0.12.2 — Activity auto-scroll toggle

A small busmon release.

- **`f` toggles Activity's auto-scroll**, from any panel. Off, the view stays where it is and the
  title counts what arrives (`auto-scroll off · 3 new`); on, it follows the newest line again. The
  title now says `auto-scroll on` / `auto-scroll off` instead of `live` / `paused`. Moving up in
  Activity still turns it off and `End` / `G` still turns it back on.
- **Today's day separator** reads `── Wed 2026-10-14 - (today) ──`, with `(today)` in green.

Upgrade: `./setup.sh update`, then quit and reopen busmon.
