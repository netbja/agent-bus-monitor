# v0.20.0 — agent-bus as a herdr plugin

This checkout is now the herdr plugin `netbja.agentbus`. `./setup.sh install` links it with
`herdr plugin link`: the plugin root is the checkout, nothing is downloaded and there is no
`[[build]]` step. The third-party herdr-plus plugin is no longer installed or needed. A herdr-plus
that an older setup installed is reported by `./setup.sh status` and never removed. setup changes
only what it wrote itself. It unlinks only the registration it recorded, and it replaces only its
own, unedited key-binding block.

## The Projects picker (`Ctrl+B` then `Up`)

`busmon --pick` lists the project templates in `~/.config/agentbus/projects`, together with what the
broker knows about each one: `present`, `absent` or `?`. Type to filter by name or directory. Enter
opens a project only after a fresh existence check, bounded to 2 s, confirms it on the broker. The
picker then runs `agentbus up <p>` off the event loop, and that `up` outlives the picker. The picker
writes nothing to Redis and never provisions a project. For an absent project it shows the command
to type: `agentbus up <p> <path>`.

From herdr's action menu, **Agent Bus: busmon** opens busmon for the focused workspace's project. If
that workspace is not a project, it opens the picker instead and says why. If busmon cannot start,
the pane stays open with the error until you press a key.

## Templates and sessions

- Templates live in `~/.config/agentbus/projects` (`AGENTBUS_PROJECTS_DIR`). Bootstrap and `up` both
  resolve that directory through `agentbus roles projects-dir`. There is no migration code: move
  existing templates once by hand (see Upgrade).
- `agentbus up` takes the herdr session from `--session`, then `HERDR_SESSION`, then
  `HERDR_SOCKET_PATH` (`…/sessions/<name>/herdr.sock`, or `…/herdr/herdr.sock` for `default`). It
  refuses to start services when it cannot tell the session. It finds the herdr binary in
  `HERDR_BIN_PATH`, then `HERDR_BIN`, then `herdr`.

## Health

The installed-versions check now covers the `netbja.agentbus` plugin. A plugin that is not
registered, is registered from another checkout, or carries a version different from the binary's
reads `warn`. An unreadable registry reads `unknown`. The version is not compared on a `dev` or
untagged (`git describe` with a suffix) build.

## Fixed after the first install

On herdr 0.9.3, `Ctrl+B` then `Up` opened nothing, because herdr refuses `--workspace` for plugin
panes (#92). The picker, an overlay, now opens over the active pane. busmon, a zoomed pane, opens
with `--target-pane`.

## Upgrade

```sh
./setup.sh update
mkdir -p ~/.config/agentbus/projects
mv "$(herdr plugin config-dir cloudmanic.herdr-plus)"/projects/*.toml ~/.config/agentbus/projects/
herdr plugin unlink cloudmanic.herdr-plus   # optional: nothing needs herdr-plus any more
```
