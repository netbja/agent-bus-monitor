# v0.17.1 — a gauge bar for each provider's quota in busmon

busmon's header showed a provider's tightest quota window as a bare percentage
(`claude 5h 52%`). It now draws a bar before the percentage (`claude 5h ██████░░░░ 52%`):
10 cells in the wide layout, 5 in the medium one; the narrow layout keeps the percentage alone.
The colour still follows the thresholds, and `held`, `?` and the pace suffixes are unchanged.

Also: the demo bus (`scripts/busmon-demo.sh`) seeds the dispatcher's `windows` budget format, so
the README screenshot shows what an install shows. Documentation: project and host names that
are not public were replaced by generic ones (PR #83).

Update with `./setup.sh update`. Nothing to restart: only busmon changed.
