# v0.17.4 — reachable role tools, safe session resume, and both quota windows

`setup.sh install` and `update` now install `agent-launch` and `agent-spawn` in `BIN_DIR` as
symlinks to the repository scripts. The scripts resolve their target before loading shared code;
status reports the links and uninstall removes only links that point to this repository's files.

Resume a Claude Code conversation through `agent-launch <role> <project> --resume <session-id>`.
This keeps the launcher's role settings and Agent Bus environment attached. Do not run
`claude --resume` by hand. Other clients reject resume until their native flags are supported.

busmon shows both fresh account quota windows per provider in wide and medium layouts. Wide uses
short and long bars; medium shows percentages; narrow keeps the tightest window. Hold, age and pace
markers follow their window. Agent detail has one Account row and states that the provider's quota
is shared by every agent using that account. `i` in an agent detail opens a compose window addressed
to that agent; Enter and `!` still open structured asks.
