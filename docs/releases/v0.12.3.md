# v0.12.3 — an agent waiting for you; auto-scroll stays on

After a clean restart, master sent a report with four decisions only the human could take, and
stayed `working`: nothing told the human it was their turn.

## New

- **State `waiting`: a person must decide.** `agentbus status master waiting "<the decision>"`.
  busmon sorts the agent first, draws ♙ with a slow pulse (bright, normal, dim, normal, one step
  per second), shows `♙ 1 waiting for you` in the header, and rings the terminal bell once per new
  waiting declaration, so herdr marks the busmon tab even when it is hidden. A waiting agent is
  never hidden as dormant. `agentbus shutdown` counts it as busy.
- **The master skill** now declares `waiting` for every decision it needs from the human (full
  question in a report, its id in the message) and returns to `working` once answered. Peers
  keep `idle` + armed when they wait for another agent, `blocked` for a 4-eyes gate.

## Changes

- **Activity auto-scroll stays on** when you select, click or open a line: only `f` and a wheel
  scroll up turn it off, `End` turns it on. `Esc` first clears the selection.

Upgrade: `./setup.sh update`, then reopen busmon. Running agents keep the skill text they booted
with: tell master once, or restart it, to pick up the `waiting` rule.
